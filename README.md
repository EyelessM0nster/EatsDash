# EATSDASH — книга отзывов

## Запуск

```powershell
cd EatsDash
dotnet run
```

## Модерация

- Учётная запись задаётся в `appsettings.json` → секция **Moderator** (`UserName`, `Password`, `DisplayName`).
- По умолчанию логин **`moderator`**, пароль **`Mod_2026!`** — **смените пароль в продакшене**.
- После запуска приложения пользователь создаётся автоматически и получает флаг модератора.
- Панель: **`/Moderation`** (ссылка «Модерация» в шапке и в личном кабинете).
- В очереди — отзывы со статусом «на модерации» (после жалобы). Действия: **Одобрить** (снова на главной) или **Отклонить** (удаление).

## Новое в этой версии

- **Личный кабинет** (`/Account/Profile`) — никнейм, настройки, смена пароля, выход
- Выбор **курьера** при создании/редактировании отзыва
- **Жалоба** скрывает отзыв и отправляет на модерацию
- Статистика по центру карточки
- Цветные аватары (фиолетовые и золотые оттенки)

## Если что-то не работает

Удалите `eatsdash.db` и перезапустите проект.
